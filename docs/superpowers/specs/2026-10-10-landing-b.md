### Polish (the owner's main ask)

| Id | Requirement |
|---|---|
| P1 | Spacing: one vertical rhythm for every section (the same top and bottom space, and the same heading-to-body gap), on the DESIGN token scale. Left edges align to one grid. No section looks crowded, and none leaves a dead empty band. |
| P2 | Every interactive element has designed hover, focus-visible, active and disabled states: links, Copy, the dial, Share, the tune selects, every footer link. Copy shows "Copied" feedback and returns. |
| P3 | Motion uses DESIGN's Motion tokens (durations and easings). Each section's entrance is one restrained scroll-driven reveal, the same family everywhere. The strike-throughs draw in on scroll. The dial turns with a settled spring, never a jump. Changing the theme cross-fades without replaying anything. |
| P4 | Overture (W1's lifecycle and clock, `lib/site/overture.mjs`): on a first visit, the hands' letters settle into place, the gap closes to its final width, and the accent dot lights. That is all, under the existing 2000ms deadline and skippable. Return visits arrive settled. |
| P5 | Nothing moves on its own except the overture and the approved marquee, text-ribbon and word-relay. Scroll-driven motion is fine, because the person is doing it. Reduced motion shows every section settled, with no scroll motion, and the dial still works. `npm run check:motion-contract` passes. |
| P6 | The pictures (hands and zero) are precomputed at build time from public-domain sources into compact data (rows, runs and weights), so the page does no image sampling. Source images are not shipped. Rendering avoids layout thrash: content-visibility on offscreen sections, and no layout read inside scroll handlers. The layout does not shift as fonts load. |
